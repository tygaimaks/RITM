# Ритм — Персональный ИИ-планировщик школьника

**Ссылка на бота в MAX:** https://max.ru/ideya_fiks_157_bot

«Ритм» — это интеллектуальный ассистент для школьников, родителей и учителей, встроенный в мессенджер MAX. Бот помогает планировать день, не забывать о домашних заданиях, снижает уровень стресса и адаптирован под детей с ОВЗ.

## 🛠 Требования для запуска
Перед запуском убедитесь, что на вашем компьютере установлено следующее:
* **Python 3.12** или выше (скачать можно с официального сайта [python.org](https://www.python.org/downloads/)). При установке обязательно поставьте галочку **"Add Python to PATH"**.
* **Git** (опционально, если вы скачиваете код через терминал).
* **Docker Desktop** (опционально, если вы хотите запустить через контейнер).
