# Ритм — Персональный ИИ-планировщик школьника

**Ссылка на бота в MAX:** https://max.ru/ideya_fiks_157_bot

«Ритм» — это интеллектуальный ассистент для школьников, родителей и учителей, встроенный в мессенджер MAX. Бот помогает планировать день, не забывать о домашних заданиях, снижает уровень стресса и адаптирован под детей с ОВЗ.
